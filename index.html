Un outil conçu pour accompagner les personnes handicapées dans la gestion de leur quotidien

MEMO permet de programmer des rappels vocaux via une application mobile et de les envoyer à un appareil autonome basé sur ESP32.

Découvrir le projet

Le projet

MEMO permet à un adulte responsable de programmer des rappels vocaux via une application mobile et de les envoyer à un appareil autonome. L'objectif est d'aider les personnes ayant des troubles cognitifs à mieux structurer leur quotidien et à maintenir leurs routines.
