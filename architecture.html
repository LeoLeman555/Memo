Architecture du système

Voici l’architecture logicielle complète du système Memo, telle qu’implémentée et versionnée sur GitHub. Le projet est structuré en deux parties principales : une application mobile en React Native et un firmware embarqué en MicroPython sur ESP32.

L’application mobile permet de configurer les rappels et d’envoyer les données, tandis que l’ESP32 exécute le système de manière autonome via un stockage local et un RTC matériel.

Le code source est versionné sur GitHub, garantissant une architecture modulaire, maintenable et traçable.

Hardware

ESP32, alimentation, carte SD et module audio. Conception physique robuste adaptée à l’usage quotidien.

Firmware

MicroPython embarqué : gestion BLE, stockage, RTC et déclenchement autonome des alarmes.

Application mobile

Application React Native : interface utilisateur, génération TTS et transfert BLE vers l’ESP32.
