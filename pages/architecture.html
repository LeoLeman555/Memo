Architecture du système

Documentation technique

Cette section présente l’architecture complète du système MEMO telle qu’implémentée et versionnée en open-source sur GitHub.


Voir le projet sur GitHub

L’ensemble du projet est donc accessible publiquement, permettant à tout développeur de cloner, analyser, modifier et réutiliser le système. Le dépôt GitHub contient l’intégralité du code source, l’historique des évolutions et facilite la maintenance ainsi que les contributions externes.

Pôles

Hardware

ESP32, alimentation, carte SD et module audio. Conception physique robuste adaptée à l’usage quotidien.

Firmware

MicroPython embarqué : gestion BLE, stockage, RTC et déclenchement autonome des alarmes.

Application mobile

Application React Native : interface utilisateur, génération TTS et transfert BLE vers l’ESP32.
